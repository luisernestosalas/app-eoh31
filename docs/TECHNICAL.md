# Documentación Técnica - CRM Cliente/Notas

## Información General

**Aplicación:** Sistema CRM para gestión de clientes y notas  
**Stack Tecnológico:** HTML + JavaScript  
**Repositorio:** https://github.com/luisernestosalas/app-eoh31  
**URL de Producción:** https://app-eoh31-80uzrifp6-luisernestosalas-2775s-projects.vercel.app  
**Plataforma de Deploy:** Vercel  

## Arquitectura

### Frontend
- **HTML5**: Estructura semántica de la aplicación
- **JavaScript ES6+**: Lógica de negocio y manipulación del DOM
- **CSS3**: Estilos y diseño responsivo (implícito)

### Almacenamiento
- **LocalStorage**: Persistencia de datos en el navegador del cliente

## Funcionalidades Principales

### Gestión de Clientes
- Creación de nuevos clientes
- Visualización de lista de clientes
- Edición de información de clientes
- Eliminación de clientes
- Búsqueda y filtrado de clientes

### Sistema de Notas
- Creación de notas asociadas a clientes
- Visualización cronológica de notas
- Edición de notas existentes
- Eliminación de notas
- Categorización de notas por cliente
