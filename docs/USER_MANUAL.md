# Manual de Usuario - CRM con Clientes y Notas

## ¿Qué es esta aplicación?

Es una aplicación web para gestionar clientes y sus notas. Te permite:
- Guardar información de tus clientes
- Agregar notas a cada cliente
- Buscar y organizar la información

## ¿Cómo acceder?

Abre tu navegador web y ve a:

https://app-eoh31-80uzrifp6-luisernestosalas-2775s-projects.vercel.app


## Funciones principales

### 1. Ver clientes
- Al abrir la app, verás la lista de todos tus clientes
- Cada cliente muestra su información básica

### 2. Agregar un cliente nuevo
1. Busca el botón **"Agregar Cliente"** o **"+"**
2. Completa los campos:
   - Nombre del cliente
   - Teléfono
   - Email
   - Otros datos que pida el formulario
3. Haz clic en **"Guardar"**

### 3. Ver detalles de un cliente
- Haz clic sobre el nombre del cliente
- Se abrirá una pantalla con toda su información

### 4. Agregar notas a un cliente
1. Entra a los detalles del cliente
2. Busca la sección **"Notas"**
