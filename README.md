# CRM - Gestión de Clientes y Notas

Una aplicación web simple y eficiente para la gestión de clientes y sus notas asociadas, desarrollada con HTML y JavaScript vanilla.

## 🚀 Demo

**URL de la aplicación:** [https://app-eoh31-80uzrifp6-luisernestosalas-2775s-projects.vercel.app](https://app-eoh31-80uzrifp6-luisernestosalas-2775s-projects.vercel.app)

## 📋 Características

- ✅ **Gestión de Clientes**: Crear, editar, visualizar y eliminar clientes
- ✅ **Sistema de Notas**: Añadir notas personalizadas a cada cliente
- ✅ **Interfaz Intuitiva**: Diseño limpio y fácil de usar
- ✅ **Almacenamiento Local**: Los datos se guardan en el navegador
- ✅ **Responsive**: Compatible con dispositivos móviles y desktop
- ✅ **Sin Dependencias**: Desarrollado con tecnologías web nativas
